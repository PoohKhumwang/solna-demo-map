Solna demo geodata on an ArcGIS map

The cleaned demo GeoPackage drawn with the ArcGIS Maps SDK for JavaScript. Click a feature for its attributes, pick an issue in the list to zoom to it, or use the tools on the map: search, layers, basemaps, measuring, sketching, elevation profile, print and coordinates.

Map tools

Top left
Zoom, home, compass, my location, full screen, then: measure distance, measure area, sketch, elevation profile.
Top right
Search (places, addresses, manhole and pipe ids), layers (legend, opacity, zoom to), legend, basemaps, bookmarks, print / export, coordinates (incl. SWEREF 99 TM).
Layers
Demo data: work area, pipes, manholes and a 5 m pipe buffer (off by default). Reference overlays: hillshade, roads, place names (off by default). My sketches.
Basemaps
Topographic, streets, imagery, imagery with labels, light and dark gray canvas, OpenStreetMap.
Under the map
Attribute table for manholes and pipes. Select a row to highlight the feature.

About the data

Made-up demo data for the Yesper tutorial, from demo_geodata_solna_clean.gpkg: 13 manholes, 6 pipes (656.6 m) and one work area. Stored in SWEREF 99 TM (EPSG:3006), embedded here as GeoJSON in WGS84.

Basemaps, overlays, elevation, geocoding and printing use Esri's public services; OpenStreetMap tiles © OpenStreetMap contributors. The page needs an internet connection to load the SDK and the map tiles.
